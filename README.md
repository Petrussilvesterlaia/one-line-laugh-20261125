# one-line-laugh-20261125

A tiny Python program that writes one funny line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

It writes the line, reads the file back, and checks that it is UTF-8 text
of 1 to 200 characters, exactly one line, and not only whitespace.
